# 沃太售后服务工作台 · 前端 Demo

售后工单智能分诊与流转系统的首期可交互演示。Angular 22 + 独立组件 + Signals，纯前端内存态，复用仓库内 `data/` 的模拟数据包（1.0.0），不接入真实模型或外部通知。界面支持 7 种语言切换：中文、English、Deutsch、Nederlands、Español、Français、Italiano。

## 启动

```bash
npm install
npm start
```

浏览器访问 http://localhost:4200 。生产构建：`npm run build`，输出在 `dist/servicedesk`。

> 首次 `npm install` 若因 Windows 文件占用出现 ENOTEMPTY，重新执行一次即可。

## 界面语言

右上角语言选择器可切换 `中文 / English / Deutsch / Nederlands / Español / Français / Italiano`，选择结果保存在浏览器本地。已覆盖：导航、页面标题、KPI、筛选与排序、表头、状态 / 优先级 / 风险徽标、工单详情页签与主要操作、风险接管与处置表单、相对时间与等待时长。

演示数据的业务内容（工单标题与摘要、客户原文与合成译文、团队 / 人员名称）、部分说明性长文本和操作结果提示仍保留中文或数据原语言；这是模拟数据的一部分，不是未翻译的界面框架。

## 页面

| 路由 | 页面 | 主要能力 |
| --- | --- | --- |
| `/dashboard` | 服务总览 | 实时 KPI、风险队列、我的待办、状态/国家/类别分布、积压最久工单；卡片可下钻 |
| `/tickets` | 工单中心 | 关键词/状态/优先级/类别/国家/语言/团队/风险/时效筛选，排序，分页；筛选在 SPA 内保留并写入 URL |
| `/tickets/:id` | 工单详情 | 概览、原始反馈与对话、AI 分诊复核、派工与协同、处理与结案、时间线；右侧固定设备/SLA/责任信息栏 |
| `/risk` | 风险与超时 | 当前风险、待人工接管、首响超时、解决目标超时四视图；确认接管、记录缓解、手工升级 |

## 可操作的演示路径

1. **AI 复核 → 派工 → 处理 → 结案**：`/tickets/WO-0001` → 「AI 分诊复核」确认或修改建议 → 「派工与协同」选择可用人员并确认派工 → 「处理与结案」开始处理、填写结果、标记解决、填写客户确认依据后关闭。
2. **人工更正 AI 建议**：打开任一待复核工单，在复核页修改类别/优先级/团队并填写原因；原建议保留，修改值、操作者、时间与原因写入复核记录和时间线。
3. **风险接管**：`/risk` → 选择风险工单 → 填写接管说明和下次更新预期 → 确认人工接管 → 记录风险缓解。
4. **手工风险升级**：风险页右上角「手工升级工单」，输入任意未终止工单编号并按 P0 处理；缺 SN 不阻塞。
5. **重复/复发与重开**：`/tickets/WO-0006` 已关闭，可在「处理与结案」填写复发证据重开；旧周期超时记录保留，新周期重新计时。
6. **筛选与下钻**：服务总览任一 KPI 或分布条可进入工单中心并带上筛选条件；返回列表后筛选保留。

所有操作只写入浏览器内存，刷新或顶部「重置演示数据」会恢复种子数据（492 条工单、1,316 条消息、1,774 条事件）。

## 数据与口径

- 数据目录：`data/seed`、`data/reference`、`data/demo`，通过 `angular.json` 的 assets 直接以 `/data/**` 提供，**未复制或改写数据集**。
- 冻结演示时钟：`2026-10-24T04:00:00Z`（北京时间 12:00）；页面按下 UTC+8 展示。
- 超时判定：未解决、尚无客户可见人工回复，且演示时钟严格大于首响到期时间。
- 优先级为 `null` 的 28 条工单显示「待判定」，不并入 P0—P3 统计。
- AI 建议全部标记「预设演示建议」；未接入真实模型。界面无 emoji，仅浅色模式。

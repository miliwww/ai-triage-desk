# 沃太能源售后工单课题：公开信息调研与数据设计依据

核查日期：2026年10月24日。本文服务于课题8“售后服务工单的分诊与流转”的模拟数据建设，是后续PRD的调研底稿。本文不是完整PRD，也不是沃太内部业务报告。

## 1. 企业与业务背景

沃太能源的英文品牌是AlphaESS。官方企业简介将其业务描述为储能产品研发、生产、销售与能源解决方案，成立于2012年，覆盖家庭、工商业以及源网侧等场景，并涉及BMS、EMS、系统集成和云平台能力。[官方企业简介](https://www.alphaess.cn/company-profile)

对售后产品设计的意义：不同客户对“设备异常”的理解和处理能力不同。家庭业主更需要清楚的说明与进度反馈；安装商能够提供调试和现场信息；工商业和大型项目运营人员需要把设备、站点及服务团队联系起来。因此模拟数据分别建立客户、站点、设备和工单，不把它们塞在一列文本里。

官网不同年份的材料所述出货量、覆盖国家数量等规模数字可能不同。本数据包不据此设定真实工单规模、故障率、区域销量或客服人数。492条工单只是演示规模。

## 3. 已确认的服务入口与流程信息

AlphaESS公开帮助文档说明，支持菜单可访问产品资料和在线服务中心，客户可以创建工单并查看进度。建议报修提供设备SN、问题发生时间、状态消息、异常现象及相关截图；安装、调试或电网设置等问题通常可以先联系安装商。[官方帮助文档](https://docs.alphaess.com/portals/portal-home-owners/vpp-apps-and-support/help-and-support.html)

因此本数据包设置了原始来件、缺失字段、资料补充、安装商参与、工单状态和对话记录。系统首先应把客户说过的信息整理好，减少重复追问，再由合适的人员继续处理。

官方2023年度报告描述过AlphaCloud客诉渠道、服务过程跟踪及相关处理制度。这属于历史佐证，不能证明2026年当前后台的具体界面、流程细节或服务时限。[2023年可持续发展报告](https://www.alphaess.cn/Public/Uploads/uploadfile/files/20240703/AlphaESS_ESG_Report_CN_2023.pdf)

欧洲官方联系页也提示技术问题应使用工单系统，可作为多地区服务入口的补充依据。[欧洲联系页](https://eu.alphaess.com/pages/contact-us)

从这些公开实践可以推导，本课题的可展示价值是缩短信息收集和转交过程、降低遗漏、让进展可见。不能据此认定沃太现有系统缺少这些能力，也不能把通用AI问答描述为已验证的竞争优势。

## 5. 本数据包假设的业务流程

客户/安装商反馈 → 接收来件 → AI整理原文和缺失项 → 提出类别、优先级及团队建议 → 人工复核 → 分派 → 处理/等待资料/备件/上门/升级 → 记录结果 → 确认关闭；复发可重开，新风险重新评估。

AI负责整理与建议：保留原始描述、区分观察和推测、标记信息不足、提出路由、草拟回复、提醒超时。人工负责关键决定：确认派工、认定根因、决定是否上门、核验保修、确认退换赔付、合并与关闭。模拟工单中的置信度是设定值，不能解释为真实模型校准后的概率。

安全风险优先人工接管。缺SN不能成为延迟升级的理由；明确否定“烟雾/异味”的句子不能只靠关键词误报；未知故障码不能推断成某个真实部件故障。这里不提供维修、拆机、带电测量或设备控制指令。

## 6. 明确的虚构项和待验证项

| 项目 | 本数据包处理方式 | 后续需要确认 |
| --- | --- | --- |
| 客户、联系人、设备SN、站点 | 全部虚构，邮箱使用example.invalid | 实际数据字段与授权方式 |
| 团队与人员 | 演示区域/技能分工，无真实姓名 | 实际组织、职责、外包与安装商协同方式 |
| P0—P3及服务目标 | 演示规则；24小时连续UTC计时，不暂停 | 官方分级、工作时间、节假日及暂停规则 |
| 工单流转、权限和审批 | 为Demo定义；含待复核、待补充、待备件等 | 当前系统状态与审批要求 |
| 常见问题与数量分布 | 人工编写场景＋确定性变体，刻意覆盖边界 | 实际渠道、语言与问题分布 |
| 故障原因、保修、赔偿 | 不自动下结论 | 授权知识与人工认定依据 |
| 成功率与服务提升 | 不虚构提升比例 | 上线前后同口径的真实基线 |

初期验证可观察：信息补全率、类别及路由的人工修改率、首次人工回复耗时、超时积压、重复来件与复发处理情况。此包只能验证字段、流程和计算逻辑，不能提供真实业务改善结论。

机器可读来源见`sources.json`；字段层面出处见产品和公司资料中的`source_ids`。未直接有公开证据的内部操作规则均按演示假设处理。
